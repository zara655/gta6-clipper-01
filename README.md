GTA 6 took 13 years... my AI clipped it in minutes: a 12-second vertical
Short cut from Rockstar's Grand Theft Auto VI Trailer 2 by an AI agent —
helicopter boat chase into a jet ski run into the motorcycle-and-plane
beat, hook text on screen, and a make.fun pitch end card. Watch it:
https://www.youtube.com/shorts/2skOcmXNDhE

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `VIDEO.json` (the video's address) to the output
directory, where the bounty gate reads it.
